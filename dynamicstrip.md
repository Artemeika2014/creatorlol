Версия: 6.2

Платформа: LoLAllApps (все приложения из магазина)

--------------------------------------------------------------------------------
1. ЧТО ЭТО ТАКОЕ
--------------------------------------------------------------------------------
Dynamic Strip — это системная плашка в верхней части экрана LoLOS. 
Она висит ПОВЕРХ всех приложений и позволяет показывать статус вашей задачи, 
не занимая весь экран.

Типичные сценарии использования:
- Прогресс загрузки или обработки
- Счётчик матча / уровень / опыт
- Статус выполнения задачи
- Таймеры и напоминания

Пользователь видит вашу активность даже когда свернул ваше приложение.

--------------------------------------------------------------------------------
2. КАК ЭТО РАБОТАЕТ
--------------------------------------------------------------------------------
Ваше приложение запускается внутри iframe в изолированной среде (sandbox). 
Вы общаетесь с LoLOS через объект window.LoLOS, который автоматически 
инжектируется в ваш HTML.

Все методы возвращают Promise. Их можно вызывать с await или без.

Пример:
  await window.LoLOS.dynamicStrip.show({ ... });

--------------------------------------------------------------------------------
3. МЕТОДЫ API
--------------------------------------------------------------------------------

--- МЕТОД 1: show(data) — Показать плашку ---
Создаёт (или заменяет текущую) плашку.

Пример:
  window.LoLOS.dynamicStrip.show({
      type: 'timer',
      title: 'Загрузка: 0%',
      icon: '📥',
      progress: 0,
      pausable: true,
      color: '#5bc0ff',
      pauseLabel: '⏸ Пауза',
      resumeLabel: '▶ Продолжить',
      cancelLabel: '✕ Отмена'
  });

Параметры:
  type        (string)  — Обязательно. 'timer' (универсальный) или 'music'
  title       (string)  — Обязательно. Главный текст. До 25 символов.
  icon        (string)  — Необязательно. Эмодзи или URL картинки.
  progress    (number)  — Необязательно. Прогресс от 0 до 100.
  pausable    (boolean) — Необязательно. Показывать ли кнопку паузы.
  isPaused    (boolean) — Необязательно. Текущее состояние паузы.
  color       (string)  — Необязательно. Цвет акцента в hex (например, '#5bc0ff').
  pauseLabel  (string)  — Необязательно. Текст кнопки паузы.
  resumeLabel (string)  — Необязательно. Текст кнопки возобновления.
  cancelLabel (string)  — Необязательно. Текст кнопки отмены.


--- МЕТОД 2: update(data) — Обновить данные ---
Обновляет уже показанную плашку БЕЗ анимации выезда.

Пример:
  window.LoLOS.dynamicStrip.update({
      title: 'Загрузка: 45%',
      progress: 45
  });

Можно передавать любые поля из списка выше. Остальные поля сохраняются.
Типичный сценарий: обновлять прогресс каждые N мс.

  setInterval(() => {
      progress++;
      window.LoLOS.dynamicStrip.update({
          title: 'Загрузка: ' + progress + '%',
          progress: progress
      });
  }, 500);


--- МЕТОД 3: hide() — Скрыть плашку ---
Убирает плашку с экрана (с анимацией).

Пример:
  window.LoLOS.dynamicStrip.hide();

Вызывайте, когда задача завершена или отменена.


--- МЕТОД 4: onAction(callback) — Подписаться на действия ---
Когда пользователь нажимает кнопки на раскрытой плашке, LoLOS 
отправляет вам событие.

Пример:
  window.LoLOS.dynamicStrip.onAction((action, value) => {
      if (action === 'pause') {
          togglePause();
      }
      if (action === 'cancel') {
          stopTask();
          window.LoLOS.dynamicStrip.hide();
      }
  });

Доступные action:
  'pause'  — нажата кнопка «Пауза/Продолжить»
  'cancel' — нажата кнопка «Отмена»

--------------------------------------------------------------------------------
4. ПОЛНЫЙ ПРИМЕР (HTML)
--------------------------------------------------------------------------------
<!DOCTYPE html>
<html>
<head><meta charset="UTF-8"></head>
<body>
    <button onclick="startTask()">Запустить задачу</button>
    <button onclick="stopTask()">Остановить</button>

<script>
    let progress = 0;
    let isPaused = false;
    let isRunning = false;
    let interval = null;

    function startTask() {
        if (isRunning) return;
        isRunning = true;
        isPaused = false;
        progress = 0;

        window.LoLOS.dynamicStrip.onAction((action) => {
            if (action === 'pause') {
                isPaused = !isPaused;
                if (isPaused) {
                    clearInterval(interval);
                } else {
                    interval = setInterval(tick, 250);
                }
                window.LoLOS.dynamicStrip.update({ isPaused: isPaused });
            }
            if (action === 'cancel') {
                stopTask();
            }
        });

        window.LoLOS.dynamicStrip.show({
            type: 'timer',
            title: 'Загрузка: 0%',
            icon: '📥',
            progress: 0,
            pausable: true,
            color: '#5bc0ff',
            pauseLabel: '⏸ Пауза',
            resumeLabel: '▶ Продолжить',
            cancelLabel: '✕ Отмена'
        });

        interval = setInterval(tick, 250);
    }

    function tick() {
        if (isPaused) return;
        progress = Math.min(progress + 1, 100);
        window.LoLOS.dynamicStrip.update({
            title: 'Загрузка: ' + progress + '%',
            progress: progress
        });
        if (progress >= 100) {
            clearInterval(interval);
            window.LoLOS.dynamicStrip.hide();
            isRunning = false;
        }
    }

    function stopTask() {
        clearInterval(interval);
        window.LoLOS.dynamicStrip.hide();
        isRunning = false;
        isPaused = false;
        progress = 0;
    }
</script>
</body>
</html>

5. ОГРАНИЧЕНИЯ
--------------------------------------------------------------------------------
[!] ОДНА АКТИВНОСТЬ НА ВСЮ СИСТЕМУ
Показывать может только одно приложение за раз. Если вы вызываете show(), 
а до этого была плашка другого приложения — она заменится вашей.

[!] НЕ РАБОТАЕТ, ЕСЛИ ПОЛЬЗОВАТЕЛЬ ОТКЛЮЧИЛ СТРИП
В настройках LoLOS есть тумблер «Скрывать Dynamic Strip». Если он включён, 
ваш show() будет проигнорирован. Не считайте это ошибкой.

[!] СОСТОЯНИЕ ТЕРЯЕТСЯ ПРИ ПЕРЕЗАГРУЗКЕ
Если пользователь обновит страницу (F5), выйдет из аккаунта или произойдёт 
OTA-обновление — ваш iframe перезагрузится, переменные сбросятся.
Решение: сохраняйте состояние через window.LoLOS.appData.save().

  await window.LoLOS.appData.save({ progress: progress, isRunning: true });
  const saved = await window.LoLOS.appData.load();
  if (saved && saved.isRunning) { /* продолжить */ }

[!] ПРОГРЕСС НЕ ОБНОВЛЯЕТСЯ В ФОНЕ (THROTTLING)
Если вкладка давно в фоне, браузер может придушить setInterval. 
Обновления станут реже. Это ограничение браузера, не LoLOS.

[!] РАЗМЕР TITLE ОГРАНИЧЕН
Практический лимит — ~25 символов. Более длинный текст обрежется.

--------------------------------------------------------------------------------
6. ДИЗАЙН-РЕКОМЕНДАЦИИ
--------------------------------------------------------------------------------
ЦВЕТА:
- Используйте контрастные цвета — они хорошо видны на чёрной плашке.
- Хорошие варианты: #5bc0ff (синий), #4ade80 (зелёный), #ff3b8b (розовый), 
  #ff9500 (оранжевый).
- Избегайте тёмных цветов (#000, #1a1a2e) — они не видны на чёрном фоне.

ИКОНКИ:
- Используйте один эмодзи для мини-вида (наиболее читаемо).
- Для брендинга — передавайте URL своей иконки (квадратная, минимум 64x64).

ТЕКСТЫ КНОПОК:
- Короткие — до 12 символов.
- Примеры: «⏸ Пауза», «▶ Продолжить», «✕ Отмена», «⏹ Стоп», «✕ Закрыть».

ОБНОВЛЕНИЕ ПРОГРЕССА:
- Не чаще раза в 100 мс.
- Идеально — раз в 250–500 мс.

--------------------------------------------------------------------------------
7. ДИАГНОСТИКА
--------------------------------------------------------------------------------
ПЛАШКА НЕ ПОЯВЛЯЕТСЯ:
1. Проверь, что window.LoLOS существует через console.log(window.LoLOS).
2. Проверь, что пользователь не отключил стрип в настройках.
3. Проверь, что не забыл type: 'timer' — это обязательное поле.

ПЛАШКА НЕ ОБНОВЛЯЕТСЯ:
1. Убедись, что update() вызывается после show().
2. Проверь, что в update() передаёшь те же поля, что меняешь.

КНОПКИ НЕ РАБОТАЮТ:
1. Убедись, что подписался на события через onAction() ДО вызова show().
